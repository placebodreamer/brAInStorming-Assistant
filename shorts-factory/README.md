# Shorts Factory (proof of concept)

A minimal, **100% free/open-source** pipeline that turns a handful of character
stills into a captioned, narrated, vertical (9:16) YouTube Shorts video —
the "reusable stills + cheap motion instead of expensive generative video"
approach.

No paid APIs, no video-generation credits (Pika/Runway/etc. are not used).
Everything runs locally with:

- **ffmpeg** — Ken Burns pan/zoom on stills, captions (`drawtext`), audio
  mixing, encoding
- **espeak-ng** — offline text-to-speech narration
- a self-synthesized sine-wave "chiptune" background bed (no licensing
  concerns, generated by ffmpeg itself)

> Note: there is no `/ai-cli` or `ai video` command installed in this
> environment (those aren't real tools here) — `scripts/make_short.sh` is
> the actual working equivalent, built from the open-source tools above.

## Layout

```
shorts-factory/
  assets/milo/          reusable character stills (the "Milo" character)
  episodes/milo-01-slide/
    01_intro.jpg ...     per-episode scene images
    scenes.tsv            image<TAB>narration/caption line, one per scene
    output.mp4             rendered Short
  scripts/make_short.sh   the pipeline
```

## Usage

```bash
./scripts/make_short.sh episodes/<episode-dir>
```

`episodes/<episode-dir>/scenes.tsv` is a tab-separated file: one line per
scene, `image_filename<TAB>narration/caption text`. The script:

1. Generates narration audio per line with `espeak-ng`.
2. Pads each line with head/tail silence to get a scene duration.
3. Renders a Ken Burns zoom/pan clip per still, held for that duration.
4. Concatenates the clips and the narration track.
5. Mixes in a synthesized background bed.
6. Burns in captions timed to each scene.
7. Muxes video + audio into `output.mp4` (1080x1920, h264/aac).

## First episode: "Milo Goes Down the Slide"

`episodes/milo-01-slide/output.mp4` — a 4-beat mini-story (~14s) built from
4 character images: intro → climb → ready → slide & cheer. This is one
worked example of the "mini-story" format from the content strategy; the
same script works for puzzle/guess/spot/learn+play formats by changing
`scenes.tsv`.

## What this does not do

This is a mechanics proof of concept, not a finished channel. It does not
include: idea generation/novelty screening, safety/moderation checks,
metadata generation, or YouTube upload — all described in the wider
strategy doc as separate Claude-driven stages. This pipeline is the cheap
"production" stage that those stages would feed into.
